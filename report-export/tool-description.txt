Creates a downloadable Excel, Word or PDF file from data you already collected with the other tools, and starts the download for the user. Call it once at the end, after the data is gathered. Format is excel, word or pdf. Title is a short plain title. ContentJson is valid JSON: {"subtitle":"...","sections":[{"heading":"...","text":"optional note","headers":["..."],"rows":[["..."]]}]}. Copy every value exactly from the tool results, never invent values. Returns a message saying the file was created, or a plain problem.
